# Лабораторная работа №2 по линейной алгебре

Учебный проект в формате Jupyter Notebook, посвящённый методам линейной регрессии, полиномиальной аппроксимации и анализу ошибок на Python с использованием NumPy, SciPy, Matplotlib и scikit-learn.

В работе исследуются псевдорешение, построение полиномиальных моделей разной степени, среднеквадратичная ошибка, регуляризация и применение линейных моделей к данным о стоимости квартир в Москве.

Проект показывает, как инструменты линейной алгебры применяются в задачах аппроксимации, машинного обучения и анализа данных.
